# From Vulnerability to Compliance: Securing Legacy Systems at Apex Healthcare Solutions

Cybersecurity capstone project (Group 151), covering a Vulnerability Assessment and Penetration Testing (VAPT) exercise against legacy systems.

## Overview

This project simulates a security assessment for a healthcare organization running outdated infrastructure. The assessment identifies vulnerabilities across two target systems, Kioptrix and Metasploitable2, and maps findings to remediation steps and compliance considerations.

## Scope

- 6 vulnerabilities identified and documented
- Targets: Kioptrix, Metasploitable2
- Deliverable: full VAPT report with findings, evidence, and remediation guidance
